# DAG Task Graph Pipeline Scheduler

## Description
Topological DAG task scheduler executing concurrent stages, computing critical paths, and detecting cyclic dependencies for autonomous agents.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery

Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures.
